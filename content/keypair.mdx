---
title: Creating a Solana Keypair
description: Generating an identity onchain
---

This page explains what keypairs are and how to create them. 

A Keypair is your identity onchain. It is where you'll keep your SOL, your tokens, interact with other apps on Solana, and deploy your own programs.

To generate a new Keypair, run the following command:

```bash
solana-keygen new -o <FILENAME>.json
```

This will create new address and it'll store it on the `<FILENAME>.json` file. Do **NOT** enter a BIP39 passphrase.

To know your public key address, run the following command:

```bash
solana-keygen pubkey <FILENAME>.json
```

Keep the JSON file secret. Never send the file to anyone. The address you see on your terminal, you can share with anyone.
